# 随手记 · 个人记账本

一个用「氛围编程（Vibe Coding）」方式做出来的纯前端记账小项目。
打开 `index.html` 就能用，不需要安装、不需要联网、不需要后端。

## 运行方式

直接双击 `index.html`（或用浏览器打开）。

如果想用本地服务跑：

```bash
python -m http.server 8000
# 然后访问 http://localhost:8000
```

## 功能

- 记录支出 / 收入，含金额、分类、日期、备注
- 顶部自动汇总所选月份的收入、支出与结余
- 支出构成环形图（按分类占比）
- 明细按日期分组展示，支持按月份、分类筛选
- 单条删除、一键清空
- 导出 CSV（Excel 可直接打开）
- 数据保存在浏览器 `localStorage`，刷新不丢

## 技术说明

- 单页应用，原生 HTML + CSS + JavaScript，**零依赖、零构建**
- 数据完全存放在本机浏览器，不上传任何服务器
- 仅用于课程练习，未接入任何真实用户数据或密钥

## 氛围编程过程

按「描述 → 看预览 → 再描述」的节奏迭代：

1. **描述**：想要一个能记收入支出、能看分类占比的小账本
2. **看预览**：发现只有数字不够直观 → 补一个环形占比图
3. **再描述**：希望能按月份回顾 → 加了月份筛选、月份汇总和 CSV 导出
